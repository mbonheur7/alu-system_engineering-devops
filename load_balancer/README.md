# load_balancer

Exercises on load balancing with Nginx and HAProxy.

| File | Description |
| ---- | ----------- |
| 0-custom_http_response_header | Adds the X-Served-By header (server hostname) to Nginx |
| 1-install_load_balancer | Installs HAProxy and balances web-01 and web-02 with roundrobin |
